# Aplicación Questions

## Requisitos

1. Angular 17+

## 1. Pasos para la instalación de la apliación
### Instalación de paquetes

    npm install

### Servidor desarrollo
El siguiente comando inicializa el servidor local angular en `http://localhost:4200` actualizanod los cambios realizados en los archivos fuente.

    ng serve

## Code scaffolding

Run `ng generate component component-name` to generate a new component. You can also use `ng generate directive|pipe|service|class|guard|interface|enum|module`.

## Construye el proyecto para producción
El siguiente comanod contruye el proyecto y almacena los artefactos construidos en la carpeta `dist/`.

    ng build
